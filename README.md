\## 📦 اجرای پروژه



دریافت سورس:



```bash

git clone https://github.com/MayT3n/MatPlayer.git

````



ورود به پوشه پروژه:



```bash

cd MatPlayer

```



نصب وابستگی‌ها:



```bash

npm install

```



اجرای نسخه توسعه:



```bash

npm run dev

```



ساخت نسخه نهایی:



```bash

npm run build

```
